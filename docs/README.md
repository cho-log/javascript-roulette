# 🎰 탐욕의 룰렛 게임 - 기능 목록

## 📂 구조 (MVC)

```
src
├── index.js                     # 진입점: Model, View, Controller를 만들고 게임 시작
├── constants.js                 # 초기 자금, 시간, 색상(칸 수·배당), 에러 메시지
├── model
│   ├── Roulette.js              # 40칸 룰렛 생성 및 회전
│   ├── Game.js                  # 자금·라운드 관리, 베팅 차감, 결과 정산
│   └── validator.js             # 베팅 입력값 유효성 검사
├── view
│   └── GameView.js              # 화면 출력, 버튼 이벤트 연결
└── controller
    └── GameController.js        # 사용자 행동 처리, Model과 View 연결
```

---

## ✅ 기능 목록

### 1. 룰렛 (Model - `Roulette`)

- 색상별 칸 수에 맞춰 총 40칸의 룰렛을 생성한다.
  - YELLOW 21칸, GREEN 10칸, BLUE 6칸, PURPLE 2칸, RED 1칸
- 40칸 중 1칸을 동일한 확률(2.5%)로 무작위 선택해 결과 색상을 반환한다.

### 2. 게임 상태 관리 (Model - `Game`)

- 게임 시작 시 자금은 10,000원, 라운드는 0으로 초기화한다.
- 베팅 시 베팅 금액을 자금에서 즉시 차감한다.
- 룰렛 결과로 베팅을 정산한다.
  - 라운드를 1 증가시킨다.
  - 결과 색상 == 베팅 색상이면 **성공**: `베팅 금액 + (베팅 금액 × 배당)`을 자금에 더한다.
  - 결과 색상 != 베팅 색상이면 **실패**: 베팅 금액을 잃는다(추가 차감 없음).
- 자금이 0원 이하인지(파산) 판별한다.
- 다시 시작 시 자금과 라운드를 초기값으로 되돌린다.

### 3. 입력값 유효성 검사 (Model - `validator`)

- 색상을 선택하지 않으면 에러를 발생시킨다.
- 목록에 없는 색상이면 에러를 발생시킨다.
- 베팅 금액을 입력하지 않으면 에러를 발생시킨다.
- 베팅 금액이 1 이상의 정수가 아니면 에러를 발생시킨다.
  - `0`, 음수(`-100`), 소수(`1.5`), 지수 표기(`1e2`), 숫자가 아닌 값
- 베팅 금액이 현재 자금을 초과하면 에러를 발생시킨다. (보유 금액과 같으면 허용)

### 4. 화면 출력 (View - `GameView`)

- 현재 자금을 천 단위 콤마 형식(`10,000`)으로 표시한다.
- 현재 라운드를 표시한다.
- 초기 화면
  - 결과 영역과 다시 시작 버튼을 숨긴다.
  - 베팅 버튼과 중단 버튼을 활성화한다.
- 베팅 시작 직후
  - 베팅 버튼과 중단 버튼을 비활성화한다.
  - 결과 영역을 표시하고 `룰렛을 돌리는 중...` 문구를 출력한다.
- 베팅 결과
  - `룰렛 결과: {색상}`을 출력하고, 결과 색상을 시각적으로 구분한다.
  - 성공 시 `베팅 성공! +{획득 금액}원`, 실패 시 `베팅 실패! -{손실 금액}원`을 출력한다.
  - 성공/실패 메시지를 시각적으로 구분한다.
- 파산 시 룰렛 결과와 함께 `게임이 곧 종료됩니다.` 안내 문구를 출력한다.
- 게임 종료 화면
  - `게임 종료`, `최종 자금: {금액}원`, `플레이한 라운드: {라운드 수}`를 출력한다.
  - 베팅 입력 영역(색상 선택, 금액 입력, 버튼)을 숨긴다.
  - 다시 시작 버튼을 표시한다.
- 잘못된 입력 시 `alert`로 에러 메시지를 보여준다.
- 다시 시작 시 색상 선택과 베팅 금액 입력값을 비운다.

### 5. 게임 흐름 제어 (Controller - `GameController`)

- 베팅 버튼 클릭 시 입력값을 검증한다.
  - 유효하지 않으면 `alert` 후 자금·라운드·버튼 상태를 변경하지 않고 재입력을 받는다.
- 유효한 베팅이면 자금을 차감하고 룰렛을 돌린다.
- 2초(2000ms) 후 룰렛 결과를 정산하고 화면에 반영한 뒤 버튼을 다시 활성화한다.
- 결과 반영 후 자금이 0원 이하이면 버튼을 비활성화 상태로 유지하고, 2초 뒤 게임 종료 화면으로 전환한다.
- 게임 중단 버튼 클릭 시 게임 종료 화면으로 전환한다.
- 다시 시작 버튼 클릭 시 모든 상태와 화면을 초기 상태로 되돌린다.

### 6. 스타일 (`index.css`)

- 비활성화된 버튼을 시각적으로 구분한다.
- 결과 색상을 색깔별로 구분해서 보여준다.
- 베팅 성공/실패 메시지를 색으로 구분한다.

## ⚠️ 예외 상황 정리

| 입력 상황          | 예시                      | 처리                                             |
| ------------------ | ------------------------- | ------------------------------------------------ |
| 색상 미선택        | `""`                      | alert: 베팅할 색상을 선택해주세요.               |
| 없는 색상          | `BLACK`                   | alert: 올바른 색상을 선택해주세요.               |
| 금액 미입력        | `""`                      | alert: 베팅 금액을 입력해주세요.                 |
| 1 이상 정수가 아님 | `0`, `-100`, `1.5`, `1e2` | alert: 베팅 금액은 1 이상의 정수로 입력해주세요. |
| 보유 자금 초과     | 자금 10,000 / `20000`     | alert: 가진 돈보다 많이 베팅할 수 없습니다.      |
